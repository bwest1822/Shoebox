# Shoebox

Real life, not the highlight reel. A 90s-scrapbook app for weekends, kids, date nights and the goofy stuff.

## What's here
- `index.html`: the whole app in one file.

## Hosting
This deploys as a static site on Vercel (Framework preset: **Other**, no build command).

When it runs outside Claude, it uses **preview mode**: pages are saved on each person's own device,
and the auto write-up is turned off. The next step is connecting Supabase (accounts, shared feed, photo storage)
and a small server function for the Anthropic API.
